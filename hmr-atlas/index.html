现在真正要验证的结构

V9 已通过“能不能拟合”的 sanity check，但还没有通过“是否泛化、是否同坐标、是哪一部分真正有效”的研究 gate。

当前消融主候选：pointmap 提供坐标系锚，残差承担人体几何修正。

01

坐标系先于误差数字

GT 基于 GT camera，pointmap 与预测点基于 pred camera。比较前必须先统一相机/世界坐标，不能用一次 PA 对齐掩盖责任变量。

02

UV 是检索，不是输出瓶颈

UV 负责告诉 attention 去哪一片区域找证据；最终三维点需要可学习的自由度，避免 discontinuous anchor 和乘性深度链。

03

body prior 放在 readout 之后

先让 point head 表达观测，再用 DuoMo converter 做人体流形投影；不要用低维模板过早限制 dense representation。

04

预注册三个 gate

同 checkpoint、同 camera convention、同 EMDB protocol 比 FULL / NO PM / NO Δ；再与 v6b 52.1 和 param head 48.1 对照。

03 · EVIDENCE BOARD

正结果、负结果、待回访

这里按实验判决而不是论文热度排序。负结果会一直保留，直到新的观测或协议真正推翻它。

ACTIVE

V9 positional retrieval

2D PE 负责告诉 query 去哪里找；3D 输出保留自由加性残差。现在要验证的不再是‘能否拟合’，而是是否泛化、是否与预测相机和 pointmap 同坐标。

POSITIVE

DuoMo body manifold

595 点 → SMPL-X converter 在真实姿态上近乎无损，并在真实 point-head 输出上稳定降误差。它应作为默认 readout 候选，而不是附录实验。

POSITIVE

Geometry-grounded translation

人体姿态和绝对深度必须分账。后融合可以保住姿态，但 root translation 要从 pointmap / camera geometry 获得可观测证据。

CLOSED

(uv, d) as output parameterization

模板身份、指数深度、非连续锚点和移动 query 共同造成 credit assignment 病。UV 可做检索与监督，不应再做最终三维输出瓶颈。

CLOSED

Pure prior denoising of a good detector

真实 Multi-HMR 输出已经在合理人体流形附近；没有图像数据项时，冻结 motion prior 只会注入均值回归偏差。

REVISIT

Evidence-guided refinement

ScoreHMR 式 data term、遮挡/失败帧选择、per-joint 候选融合仍值得回访，因为它们引入的是新证据，而不是盲目平滑。

05 · EVALUATION CONTRACT

以后每个结果都先回答四件事

这一栏把历史上最容易制造假阳性或假阴性的 confound 固定下来，防止再被 stale checkpoint、错误相机或合成噪声误导。

FRAME

在哪个坐标系？

GT camera、pred camera、world frame 必须明说；alignment 只用于对应指标，不能替代度量定位。

CHECKPOINT

真的是同一权重？

显式 pin checkpoint、记录 hash、禁止 checkpoint-last 默认值把 pilot 和 full run 混在一起。

OBSERVATION

噪声是真实的吗？

GT + Gaussian 只能做 sanity。决定性结论必须来自真实 HMR observation 或真实遮挡/缺失。

METRIC

局部还是世界？

PA-MPJPE 看相对姿态；MPJPE/PVE 看尺度；W/WA-MPJPE、RTE 与 jitter 看世界轨迹和相机责任。
